DOCUMENTATION

HOW TO USE

01

GETTING STARTED

01
Open Pack Midi and click Login with Audiotool — log in with your Audiotool account.
02
Open your project on beta.audiotool.com and copy the URL from the browser address bar.
03
Paste the URL into the Project URL field and click Load.
04
Your tracks appear in the list. Click ↓ .mid to download a single track, or Export all to download all tracks at once.
02

TRACK NAMES

Pack Midi reads the name of the instrument (device) connected to each note track. The exported file will be named after that instrument.

IMPORTANT

Name your instruments in Audiotool before exporting — the device name becomes the track name and the file name. Double-click the device name in the studio to rename it.

03

MACHINISTE DRUM EXPORT

Pack Midi exports the first 5 channels of the Machiniste drum sampler. Each channel is mapped to a standard GM drum note:

Channel Drum Sound GM Note
CH 1Kick36 — Bass Drum
CH 2Snare38 — Acoustic Snare
CH 3HiHat Closed42 — Closed Hi-Hat
CH 4HiHat Open46 — Open Hi-Hat
CH 5Crash49 — Crash Cymbal
NOTE

If your Machiniste uses a different channel order (e.g. Snare on CH 1), you'll need to reassign the MIDI notes in your DAW after import.

04

TRACK NAME & FILE NAMING

Enter a track name before exporting — this becomes part of the file name together with your artist name and the instrument name.

FILE FORMAT

artist_trackname_instrumentname.mid
e.g. sandburgen_golden_sunrise_Pulverisateur.mid

Your artist name is taken automatically from your logged-in Audiotool account.

05

BPM

Drag the BPM display up or down to set the tempo. The BPM is written into the MIDI file so your DAW syncs correctly on import.

06

SUPPORTED DEVICES

✓
Note tracks — Heisenberg, Pulverisateur, Gakki, and all other synths with note tracks
✓
Machiniste — first 5 channels exported as GM drums (MIDI channel 10)
✗
Beatbox 8 / Beatbox 9 — not yet supported
✗
Bassline — not yet supported
